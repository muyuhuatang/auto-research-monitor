01

See one build itself from zero

Run this in a second terminal, from the project folder. It streams a worked Credit-Risk investigation through the SDK — about twenty nodes fade in and settle on a green-credibility claim. No key, no network.

python examples/demos/live_demo.py
02

Point it at a folder of your own

Restart the server in watch mode. Every file that appears or changes under that folder is classified and turned into a node, so an ordinary working directory becomes an evidence graph with no instrumentation.

python run.py --watch ./my-project

No terminal handy? Use to browse to the folder instead — same thing, without the restart.

03

Let an agent push its own reasoning

Create a task, keep the returned api_key, and have the agent POST one event per decision. This is sidecar mode: the graph is written by whatever is doing the work.

curl -X POST http://localhost:8000/api/tasks -H "Content-Type: application/json" -d '{"name":"my task"}'
