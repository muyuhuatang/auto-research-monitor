Quick start

Running in three commands.

No build step, no frontend toolchain. Clone the repo, install the Python deps, run the server, and open your browser.

Python 3.10+FastAPI + uvicornzero-build frontend
bash — auto-research-monitor-app 
# 1 — get the code
$ git clone https://github.com/muyuhuatang/auto-research-monitor-app
$ cd auto-research-monitor-app

# 2 — install dependencies
$ pip install -r requirements.txt

# 3 — launch the sidecar server
$ python run.py

→ Open http://localhost:8000
What it does

Make an agent's reasoning legible — and checkable.

Six capabilities turn a stream of agent events into a scored, traceable map of how every conclusion was earned.

Real-time galaxy

Watch the graph grow live over SSE as your agent works — then replay the whole run step by step, with every claim's score as it stood at that moment.

Sidecar for any agent

Claude Code, GPT, or your own scripts push events over a simple HTTP API or the zero-dependency Python SDK. Humans watch at a shareable URL.

Credibility scoring

Every claim is scored across 5 structural dimensions — evidence coverage, reproducibility, data provenance, statistical validity and pipeline integrity — then rated green, yellow or red.

Lineage tracing

Click any claim to highlight its full evidence chain back to the original motivation — or to reveal that it has none.

File-watcher inference

Point it at a project folder and files become typed nodes automatically — code, data, runs, results, claims — with edges inferred from temporal proximity.

Convergence & conclusions

Collapse dozens of results into ≤5 apex findings and generate a single traceable conclusion report — heuristic, or written by an LLM.

How it works

From a stream of events to an earned conclusion.

An append-only pipeline: nothing is overwritten, so the whole chain of reasoning stays auditable.

01

Your agent pushes events

It POSTs create_node / create_edge to the events API — or simply writes files into a watched folder.

02

The server logs the graph

FastAPI records an append-only evidence graph in NetworkX — typed nodes, typed edges, full history.

03

The browser renders a galaxy

Cytoscape.js streams updates over SSE into a live, scored galaxy that anyone can watch at /t/{id}.

04

Converge into a conclusion

Results collapse into ≤5 apex findings and a single traceable conclusion report — heuristic or LLM-written.

AI Agent→Events API→Evidence Graph→Live Galaxy→Conclusion

How a score is earned

Five structural dimensions. One honest color.

Scores measure the structure of the evidence chain — not how confident the prose sounds.

Evidence Coverage Is the claim backed by results, runs and artifacts?
30%
Statistical Validity Are the results statistically sound?
20%
Reproducibility Can the supporting runs be re-executed?
20%
Data Provenance Is the data traceable to a real source?
15%
Pipeline Integrity Is the chain from data to claim unbroken?
15%
