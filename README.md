# Auto-Research Monitor — GitHub Pages site

This repository is the static website for Auto-Research Monitor.

- **Website:** https://muyuhuatang.github.io/auto-research-monitor/
- **Live demo:** https://muyuhuatang.github.io/auto-research-monitor/demo/

It is generated by `scripts/build_static.py` in the app's repository, so don't edit it
by hand: change the source there, rebuild, and push the output here.

| Path | What it is |
|---|---|
| `index.html`, `media/` | The landing page |
| `demo/` | A read-only demo: the app's own dashboard and graph viewer, showing the four preloaded example runs |
| `demo/data/` | What the server returned for each example, exported as JSON |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

The demo has no server behind it. `demo/demo.js` answers the viewer's reads from
`demo/data/` and refuses anything that writes, so everything that needs a server of
your own is hidden: live streaming, watching a folder, adding tasks, the API config
and every model call. To run the full app, see the
[quick start](https://muyuhuatang.github.io/auto-research-monitor/#quickstart) on the website.
