# Auto-Research Monitor — GitHub Pages site

This folder is the static website for
[Auto-Research Monitor](https://github.com/muyuhuatang/auto-research-monitor-app). It is
generated by `scripts/build_static.py` in that repository; don't edit it by hand.

| Path | What it is |
|---|---|
| `index.html`, `media/` | The landing page |
| `demo/` | A read-only demo: the app's own dashboard and graph viewer, showing the four preloaded example runs |
| `demo/data/` | What the server returned for each example, exported as JSON |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

The demo has no server behind it. `demo/demo.js` answers the viewer's reads from
`demo/data/` and refuses anything that writes, so everything that needs a server of
your own is hidden: live streaming, watching a folder, adding tasks, the API config
and every model call. To run the full app, follow the
[quick start](https://github.com/muyuhuatang/auto-research-monitor-app/blob/main/docs/quick-start.md).

## Publishing

This folder is the `auto-research-monitor` repository, which holds the site and nothing
else; the app's source lives in `auto-research-monitor-app`. Push this folder to the
site repository's `main` branch and set **Settings → Pages → Source** to `main`, root.
The site is then at `https://muyuhuatang.github.io/auto-research-monitor/`.

To update it, rebuild from the app repository (`python scripts/build_static.py`) and
push the result again.

To check it locally:

```bash
python -m http.server 8080
# then open http://127.0.0.1:8080/
```
